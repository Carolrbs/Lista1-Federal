
# Lista de Exercícios da Federal


Aqui são exercícios do meu curso de Automação Industrial - Programação em C#.

objetivo principal é praticar operações matemáticas básicas e aplicá-las em cenários simples.

Especificamente, você provavelmente vai aprender a:

Calcular áreas: De retângulos, quadrados e triângulos. Isso envolve entender as fórmulas para calcular a área dessas figuras geométricas.

Trabalhar com as propriedades do quadrado: Calcular a área a partir do lado e a área a partir da diagonal.

Calcular médias: Tanto a média aritmética quanto a média geométrica de conjuntos de números.

Realizar conversões de unidades: Converter milhas marítimas para quilômetros.

Converter temperaturas: De graus Celsius para Fahrenheit.

Calcular áreas de círculos: A partir do diâmetro.

Realizar conversões de moedas: Converter dólares para reais.

Trabalhar com potenciação: Calcular X, Y ( onde X e Y são valores de entrada).
 
Resolver problemas de troco: Calcular o troco a ser devolvido após um pagamento.
